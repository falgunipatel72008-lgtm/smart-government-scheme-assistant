# Backend

Node.js 20+ and Express 5 API. Admin login uses MySQL credentials, scrypt password hashes, and one-hour HS256 JWTs.

1. Copy `.env.example` to `.env` and set the MySQL connection, a JWT secret with at least 32 characters, the bootstrap admin ID/password, and Cloudinary credentials.
2. Create the MySQL database named by `DB_NAME`.
3. Run `npm install`, `npm run db:migrate`, and `npm run db:seed-admin`. The seed command creates the `Education` category if needed, adds four all-India education scholarships, and idempotently seeds 100 catalog schemes. Each category in migration `023_seed_master_categories.sql` and the `Education` category has five or six distinct schemes; the Education total includes its four scholarship records. Catalog records are centrally administered Indian schemes; eligibility, benefits, geographic reach, and application windows can change, so confirm current details with the implementing ministry before applying.
4. Run `npm run dev`.

The login endpoint is `POST /api/v1/auth/login` with `{ "id": "...", "password": "..." }`. Protected endpoints use `Authorization: Bearer <token>`; `GET /api/v1/admin/me` verifies the admin middleware.

`GET /api/v1/categories`, `/api/v1/genders`, `/api/v1/states`, `/api/v1/union-territories`, `/api/v1/locations`, `/api/v1/ministries`, and `/api/v1/criteria/options` are public. The criteria options endpoint returns active dimensions grouped with their active options; gender options come from `master_gender`, while other categorical options come from `criteria_option`. Numeric dimensions have an empty `options` array. The combined locations endpoint returns `{ locations: [{ id, name, isUnionTerritory, isActive, createdAt, updatedAt }] }`. Admin JWTs are required for `POST`, `PATCH`, and `DELETE` on categories, genders, states, union territories, and ministries. Create or update categories using `multipart/form-data` with `name`, `description`, and an optional `image` file (JPEG, PNG, or WebP; up to 5 MB). Images are uploaded to Cloudinary; the database stores the secure URL and Cloudinary public ID. Categories, genders, states, union territories, and ministries have an `isActive` flag and created/updated timestamps. Migrations seed `male`, `female`, `other`, all 28 Indian states, all 8 union territories, and the 53 Union Government ministries listed in the [Government of India directory](https://igod.gov.in/ug/categories). A master value in use cannot be deleted once a scheme foreign key references it.

`GET /api/v1/schemes` returns active schemes with their ministry, categories, coverage, eligibility criteria, and formatted content. It accepts `page` (default 1), `pageSize` (default 10, maximum 50), `search`, and optional `categoryId`, `ministryId`, `stateId`, and `unionTerritoryId` filters. The response includes pagination totals and previous/next flags. `GET /api/v1/schemes/:id` returns the full detail record for one active scheme. `POST /api/v1/schemes` currently creates a scheme without authentication to support the public creation prototype. It validates active master values and criteria IDs, then saves the scheme and its ministry, categories, geographic coverage, criteria options, gender selections, numeric rules, and formatted content in one database transaction. Rich text/list sections and nested online/offline application steps are stored as JSON; eligibility mappings remain relational. Scheme creation is intentionally public only for development/reference and must be protected by the admin JWT middleware before production use.

Each schema change belongs in a new ordered `.sql` file under `migrations/`. The migration runner records applied filenames in `schema_migrations`. The admin ID and password are supplied through server-only environment variables and seeded as a scrypt hash; do not put real credentials in a migration or commit `.env`.

Migration `023_seed_master_categories.sql` seeds these active categories: Agriculture and Farming, Health and Wellness, Women and Child Development, Employment and Skill Development, Social Welfare and Empowerment, Housing and Shelter, Banking and Financial Services, Business and Entrepreneurship, Rural Development, Science and Technology, Transport and Infrastructure, Environment and Energy, Sports and Culture, Tourism and Travel, Food Security, Drinking Water and Sanitation, Labour Welfare, Tribal Development, Fisheries and Animal Husbandry, Financial Assistance, Pension and Retirement Benefits, Digital Services, Public Safety and Justice, and Child Protection and Welfare.
